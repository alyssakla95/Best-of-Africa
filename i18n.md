# Internationalization (i18n) Strategy

## Supported Languages

* **English** (`en`) [Source]
* **French** (`fr`)
* **German** (`de`)
* **Arabic** (`ar`) [RTL]
* **Hindi** (`hi`)
* **Mandarin Chinese** (`zh`)
* **Portuguese** (`pt`)

## Architecture

### Source of Truth

English (`en`) is the primary source. All content is first generated/audited in English.

### Translation Pipeline

1. **Editorial Agent** produces English variants.
2. **Kimi K2.5** (via `TranslationService`) translates variants to target languages.
    * *Instruction*: "Preserve factual content and tone. Do not hallucinate."
3. **Video Agent** generates English visuals but localized metadata (titles/captions).

### Data Model

* **Articles**: Stored with `language_code` (default 'en').
* **Variants**: Keys namespaced by language, e.g., `variant_tourist_fr`.
* **Frontend**: Client-side routing `/:lang/...`.

## Safety & Budget

* **Rate Limits**: Max 50 translations/day per language.
* **Fallback**: If a language variant is missing, show English with a "Not translated" badge.
* **RTL**: Arabic forces `dir="rtl"` and specific font handling.

## Usage

* **Frontend**: Use `useLanguage()` hook to get current lang.
* **URL**: `/fr/articles/slug`, `/ar/dashboards`
